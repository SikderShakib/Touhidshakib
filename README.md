# Touhid Shakib — Products, Software, Courses & APK

A personal storefront **and upload hub** for everything I build: digital products, problem-solving
software, courses and Android APKs.

- **Storefront** — `/` — hero, category shelves, live search, filters, product pages, download counters.
- **Upload hub** — `/admin.html` — sign in, upload a product with a cover image and a real file
  (ZIP / PDF / APK / video), edit, publish/unpublish, delete, change site text and links, back up data.
- **CV** — `/cv.html` — the original portfolio page, untouched apart from asset paths.

## Run it

```bash
npm install
npm start
```

Then open <http://localhost:3000>. The admin panel is at <http://localhost:3000/admin.html>.

**First sign-in:** username `admin`, password `touhid123`.
Change it right away from **Settings → Password**. You can also set the starting password with the
`ADMIN_PASSWORD` environment variable before the very first run.

## How uploading works

1. Open `/admin.html` and sign in.
2. Click **New product**.
3. Drop a cover image (3:2 looks best) and the deliverable file (up to 512 MB), or paste an external
   download link instead of a file.
4. Fill in title, category (Product / Software / Course / APK), tagline, price, description,
   features and tags.
5. Hit **Save product**. It appears on the storefront instantly when *Published* is on.

Uploaded images land in `uploads/images/`, product files in `uploads/files/`, and every product
record is stored in `data/db.json` (created from `data/seed.json` on first run). Download links are
counted, and deleting a product also deletes its files.

## Editing the demo content

`data/seed.json` holds the starter products and site text. Once `data/db.json` exists it is the live
database — use the admin panel for changes, or delete `data/db.json` to reset back to the seed.
Cover artwork for the demo items is generated by `node scripts/make-covers.js`.

## Project layout

```
server.js              Express server + JSON API (public storefront & admin)
lib/store.js           JSON store, password hashing (scrypt), settings
data/seed.json         Starter products and site settings
data/db.json           Live data (git-ignored, created on first run)
public/index.html      Storefront
public/product.html    Product detail page
public/admin.html      Upload hub
public/cv.html         CV / portfolio page
public/js/*.js         common helpers, storefront, product page, admin logic
public/css/*.css       Design system + admin styles
uploads/               Uploaded covers and product files (git-ignored)
scripts/make-covers.js Generates the demo cover SVGs
```

## Notes

- Sessions are kept in server memory: restarting the server signs the admin out. Product data and
  uploads stay on disk.
- The site is a Node app, so it needs a host that runs Node (Render, Railway, Fly.io, a VPS…).
  GitHub Pages can only serve the static `index.html` in the repository root (the CV).
- Back up your catalogue any time from **Settings → Backup & storage**.
